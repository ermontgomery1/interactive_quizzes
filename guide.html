You can study your own material with the same quiz and flashcard tools as the built-in sets. A flashcard deck is a plain text file. A quiz is a folder with a questions.json file and any images its questions use.

The built-in sets use exactly these formats, so they make good templates. Open them to see a complete example:

  • flashcards/flashcards.txt: a 77-card deck
  • quiz5/questions.json: a quiz that uses all three question types and images
  • quiz7/questions.json and quiz6/questions.json: more examples

1. Importing a set

In the set dropdown at the top of the page, choose + Import or manage your own sets…. Then do one of these:

  • Choose folder: pick a quiz folder, or a folder holding several quiz folders and decks. Everything inside is imported in one go.
  • Choose files: select questions.json and its images together, or a single .txt deck. Use this on iPhone and iPad, where folders can't be picked.
  • Drag and drop: on a computer, drop folders or files anywhere on the page.

Each set is checked before it's saved. If something is wrong, you'll see which question or line has the problem and what's expected, and that set isn't imported. Fix the file and import it again. Yellow notes are warnings: the set was imported, but something may not look the way you meant.

Your imported sets appear in the dropdown under Imported (this browser).

An example folder to import (names on the left become set names):
my-study-sets/
├── week8-routing/            ← quiz named "week8-routing"
│   ├── questions.json
│   ├── topology.png
│   └── bgp policy.jpg
├── week9-mac/                ← another quiz
│   └── questions.json
└── key-terms.txt             ← flashcard deck named "key-terms"

2. Flashcard decks (.txt)

One card per line: the term, a single Tab character, then the definition. The file name (without .txt) becomes the deck name. .tsv files work too.

Forwarding table→Table used in destination-based forwarding that specifies a router's local data-plane forwarding behavior based on destination IP addresses.
Per-router control→Control plane approach where a routing algorithm runs in every router and routing components interact with each other to compute forwarding tables.
Logically centralized control→Control plane approach where a distinct remote controller computes and distributes forwarding or flow tables to local control agents in routers.

The first three cards of flashcards.txt. → marks the Tab; in the real file it's an invisible Tab character.

  • Only the first Tab on a line splits term from definition.
  • Blank lines are fine. A line without a Tab is skipped, and the import tells you its line number.
  • Stars are remembered by term, so give each card a different term.
  • Cards are shown as plain text. Math notation isn't rendered on flashcards.

Easiest way to make one: use a spreadsheet

Put terms in column A and definitions in column B. Select both columns, copy, paste into a plain text editor (Notepad, TextEdit in plain-text mode, VS Code), and save as a .txt file with UTF-8 encoding. Copied spreadsheet cells are already separated by Tabs. In Google Sheets you can also use File → Download → Tab-separated values (.tsv).

Some editors turn the Tab key into spaces. If an import says no cards were found, that's the usual reason.

3. Quizzes (questions.json)

The file must be named exactly questions.json. It contains a list of questions inside square brackets, separated by commas:

[
  { "id": 1, "type": "multiple_choice", ... },
  { "id": 2, "type": "matching", ... },
  { "id": 3, "type": "short_answer", ... }
]

The quiz is named after its folder. To give it a different name, wrap the list in an object with a title. If you import with Choose files (for example on an iPhone), there's no folder name, so add a title:

{
  "title": "Week 8: Routing",
  "questions": [
    { "id": 1, ... },
    { "id": 2, ... }
  ]
}

Importing a quiz with the same name again replaces the earlier copy, which makes fixing mistakes easy.

Fields every question can have

FieldRequired?What it does
idYesA number, different for every question. Unshuffle puts questions back in id order, so number them in the order you want.
typeYes"multiple_choice", "matching" or "short_answer".
questionYesThe question text. Use \n for a line break.
answerYesDepends on the type (see below).
explanationNoShown after the question is submitted, right or wrong.
hintNoShown when Show Hint is pressed. Without one, the button is hidden.
imagesNoA list of image file names shown under the question. See Images.
figureNoA text description of the figure. Used as the image's alt text, or shown as text when there's no image.
lectureNoA short label (like "Lecture 12") shown next to the question type.
fixed_orderNotrue keeps this question's options in the written order even when Shuffle answers is on. Use it when the explanation or the choices refer to options by letter. See Shuffled answers.

Question text, options, hints and explanations can include math between $...$ (inline) or $$...$$ (on its own line), written in LaTeX. Inside JSON every backslash is doubled, so \min is written \\min.

4. The three question types

Multiple choice

options maps a letter to each choice. answer is the letter of the correct choice. From quiz 5, question 1:

{
  "id": 1,
  "type": "multiple_choice",
  "question": "True or False: With distance vector algorithm, a router learns the cost to other routers from a global topology map obtained through an iterative process of computation and exchanging info with neighbors.",
  "options": {
    "A": "True",
    "B": "False"
  },
  "answer": "B",
  "explanation": "Distance vector is a decentralized algorithm: a router never has a global topology map. ...",
  "hint": "Which routing algorithm class gives every router the complete topology, and which one only uses information from neighbors?"
}

Select all that apply: make answer a list of letters. Checkboxes replace the round buttons, and the question counts as correct only if exactly those choices are ticked. From quiz 5, question 5:

{
  "id": 5,
  "type": "multiple_choice",
  "question": "Consider the OSPF routing protocol. Which of the following characteristics are associated with OSPF (as opposed to BGP)? Select all that apply.",
  "options": {
    "A": "Is an inter-domain routing protocol.",
    "B": "Is an intra-domain routing protocol.",
    "C": "Policy, rather than performance (e.g., least cost path), determines paths that are used.",
    "D": "Finds a least cost path from source to destination within a domain.",
    "E": "Floods link state control information."
  },
  "answer": ["B", "D", "E"],
  "explanation": "OSPF is an intra-domain (intra-AS) link-state protocol: ...",
  "hint": "OSPF runs inside a single AS and is a link-state protocol. BGP runs between ASes and is policy-driven."
}

Matching

Each item in prompts gets a dropdown listing the choices. answer lists the correct choice for each prompt, in the same order as the prompts, and each answer must be spelled exactly like one of the choices. Choices can be used more than once, and you can add extra wrong choices. If you leave out choices, the dropdown lists the answers. From quiz 5, question 2:

{
  "id": 2,
  "type": "matching",
  "question": "Consider the network shown below. ... Match each router to the protocol by which it learns about the network prefix x, which is attached to AS4.",
  "images": ["ebgp_ibgp_ospf.jpg"],
  "figure": "Four autonomous systems. AS3 router 3c connects to AS4 router 4c; ...",
  "prompts": [
    "Router 3c learns about prefix x from which protocol?",
    "Router 3a learns about prefix x from which protocol?"
  ],
  "choices": ["eBGP", "iBGP", "OSPF", "RIP"],
  "answer": ["eBGP", "iBGP"],
  "explanation": "Router 3c is a gateway router with a direct eBGP session to 4c in AS4, ...",
  "hint": "eBGP runs between routers in different ASes; iBGP distributes externally learned routes to routers inside the same AS."
}

The question counts as correct only if every prompt is matched correctly. Keep choices short; long ones get cramped in the dropdown, especially on phones.

Short answer

The student types an answer, which is checked against keywords. answer is a model answer, shown after submitting. From quiz 5, question 4:

{
  "id": 4,
  "type": "short_answer",
  "question": "Router X has only the three neighbors listed below and has no direct link to destination Z. ... Compute X's new route to Z.\n\nX's next hop is ____ and its distance to Z is ____.",
  "images": ["P6-Table Fig.jpg"],
  "figure": "Neighbor A: cost from X = 2, advertised distance to Z = 7. ...",
  "answer": "Next hop B, distance 7.",
  "keywords": ["B", "7"],
  "explanation": "Apply the Bellman-Ford equation $D_X(Z) = \\min_v \\{c(X,v) + D_v(Z)\\}$. Via A: $2 + 7 = 9$. Via B: $5 + 2 = 7$. Via C: $1 + 9 = 10$. The minimum is 7, through neighbor B.",
  "hint": "For each neighbor, add the cost to reach that neighbor to the distance it advertises, then take the minimum."
}

How short answers are graded

  • An answer is marked correct if it contains at least one of the keywords (ignoring capitals), or if it matches a keyword exactly. In the example above, an answer containing just "B" counts as correct.
  • Keywords of one or two characters, like "B" or "7", must stand alone, so "7" doesn't match inside "17" and "b" doesn't match inside "bgp". Longer keywords match anywhere, even inside a longer word.
  • List the different ways a student might write the same thing, for example ["(2,4)", "(2, 4)", "R2C4"].

Because one keyword is enough, short answer suits questions with one key fact. Split a question with several required parts into separate questions, or use matching instead.

Shuffled answers

When Shuffle answers is turned on, multiple choice options and matching dropdown choices are shown in a random order. Options are relabelled A, B, C… from the top, so the letters a student sees may differ from the ones in your file. Grading still uses your answer, so you don't need to change anything.

  • A True/False pair always shows True first.
  • Options like "All of the above" or "None of the above" stay at the bottom.
  • Because letters change, an explanation such as "(B) is correct" could point at the wrong option. Add "fixed_order": true to those questions, or describe options by their content instead. Quiz 7, questions 3 and 7, use fixed_order for this reason.

5. Images and figures

  • Put image files in the same folder as questions.json (a folder inside it works too, e.g. "images": ["figs/topology.png"]).
  • List them by file name in images. Spaces in names are fine ("P6-Table Fig.jpg"). For imports, capitals don't matter.
  • Supported types: PNG, JPG/JPEG, GIF, WebP, BMP, AVIF and SVG.
  • Include the images when importing. With Choose files, select them along with questions.json. If a listed image is missing, the import tells you which one.
  • Images no question uses aren't saved, so they don't take up storage.
  • Always add a figure description too. It helps screen-reader users and appears if the image can't be shown.

6. Writing JSON without errors

JSON is strict. Most import errors come from one of these:

RuleWrongRight
Commas between items, but none after the last one"A": "True",
"B": "False",
}		"A": "True",
"B": "False"
}
Double quotes only, around every name and text{ id: 1, 'type': 'matching' }{ "id": 1, "type": "matching" }
A " inside text needs a backslash"the "best" path""the \"best\" path"
Backslashes are doubled"$\min_v$""$\\min_v$"
Line breaks inside text are written as \n"First line
second line"		"First line\nsecond line"
Numbers for id, without quotes"id": "3""id": 3

When a file isn't valid JSON, the import shows the line and column where reading stopped. The real mistake is usually just before that point, often a missing comma at the end of the previous line. Curly “smart quotes” pasted from a word processor also cause this; replace them with straight quotes.

A code editor such as VS Code highlights these mistakes as you type. The easiest start is to copy one of the built-in questions.json files and edit it.

7. Where imported sets are kept

  • Imported sets are saved in your browser on this device only. Nothing is uploaded anywhere, and nobody else can see them.
  • They don't sync between devices or browsers. To study on another device, import the files there too.
  • Clearing this site's data (cookies and site data) deletes them, and so does a private or incognito window when it closes. Keep your original files.
  • To update a set, edit your files and import again with the same folder name or title. To delete one, use Remove in the import dialog.
